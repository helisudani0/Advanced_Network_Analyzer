# Ravynel Brand System

## Product Name

Primary name: Ravynel

Product descriptor: Ravynel NDR

Tagline: Reveal every flow. Prioritize every threat.

## Naming Rationale

Ravynel is short, distinctive, and premium-sounding. It hints at speed, vigilance, and venom-like precision without using saturated cybersecurity words such as sentinel, shield, guard, cyber, secure, packet, or threat.

A quick exact web screen found no active cybersecurity or software platform using `Ravynel`; search results were dominated by biomedical/gene references for `Ravynel-like`. This is not a legal trademark opinion. Before commercial release, run formal trademark, domain, and company registry clearance.

## Logo

The logo is stored at `brand/Ravynel-logo.svg`.

The mark combines:

- a packet-lattice shield
- cyan-to-orange signal energy
- dark enterprise SaaS presentation
- a clean wordmark suitable for both product UI and marketing

## Visual System

- Background: near-black navy
- Primary: signal cyan
- Secondary: operation blue
- Alert accent: controlled orange
- Success: telemetry green
- Typography: Segoe UI / Aptos / Helvetica Neue for a professional enterprise feel

## Voice

Ravynel should sound concise, serious, and operational:

- Say `capture`, `investigate`, `prioritize`, `deploy`, and `evidence`.
- Avoid project language such as `demo`, `toy`, `basic`, or `sample data`.
- Be honest about passive visibility and deployment scope.
